# Tunemac 🎵
### Localized Music Streaming & Content Delivery for Guinea-Bissau

Tunemac is a mobile solution designed to bridge the gap between local Bissau musicians and their audience. In a market where music is often traded informally via laptops, Tunemac provides a digital platform for discovery and high-quality streaming.

## 🌍 The Problem & The Solution
In Guinea-Bissau, the music industry is highly fragmented. Tunemac aims to:
- **Digitize Local Music:** Move the "laptop-to-phone" trade into a secure mobile app.
- **Genre Focus:** Specialized categories for Gumbe, Morna, and other local genres.
- **Offline First:** Optimized for low-data environments common in frontier markets.

## 🛠️ Tech Features (Current Build)
- **State Management:** Using **Provider** for high-performance reactive UI updates.
- **Custom UI:** Hand-crafted music player interface with smooth transitions.
- **Navigation:** Deep-linking structure for sharing specific tracks.
